# Exactly Submission Bundle

Use this bundle to submit the VerifiedMarket delegate-bypass finding to Immunefi.

## Recommended use

1. Paste `exactly-verifiedmarket-immunefi-textarea.md` into the main description textarea.
2. If the form is field-based instead of one big textarea, use `exactly-verifiedmarket-immunefi-fields.md`.
3. Attach files in this order if attachments are allowed:
   1. `exactly-verifiedmarket-bypass-poc.sol`
   2. `exactly-verifiedmarket-borrow-bypass-results.json`
   3. `exactly-verifiedmarket-borrow-bypass-evidence.md`
4. Keep `exactly-verifiedmarket-triage-notes.md` handy for follow-up questions about severity or "works as intended" objections.

## Included files

- `exactly-verifiedmarket-immunefi-textarea.md`: shortest paste-ready version
- `exactly-verifiedmarket-immunefi-fields.md`: field-oriented version
- `exactly-verifiedmarket-immunefi-public.md`: full public-link version
- `exactly-verifiedmarket-bypass-poc.sol`: PoC source used in the clean-clone validation
- `exactly-verifiedmarket-borrow-bypass-results.json`: parsed PoC results
- `exactly-verifiedmarket-borrow-bypass-evidence.md`: evidence summary
- `exactly-verifiedmarket-triage-notes.md`: severity position and reviewer-objection rebuttals
- `SHA256SUMS.txt`: checksums for integrity
