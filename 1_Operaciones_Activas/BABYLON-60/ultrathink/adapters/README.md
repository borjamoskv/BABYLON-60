# Ultrathink Adapters

This directory contains external integrations and adapters for the `ultrathink` system.

## Included Adapters
- **codex-ultrathink**: Adapter for OpenAI Codex models.
- **claude-ultrathink**: Adapter for Anthropic Claude models.
- **antigravity-ultrathink**: Adapter for Google Antigravity (Nodo 4 Integration).
- **kimi-ultrathink**: Adapter nativo para Kimi-K3 (Moonshot AI). Configurado bajo el Invariante Ω202: Impone bloqueo estricto de Mid-Session Shift, gestiona la masa termodinámica vía `reasoning_effort` (low, high, max), y aplica el Cierre Teleonómico para erradicar proactividad ilusoria en la KV-Cache (2.8T parameters).
