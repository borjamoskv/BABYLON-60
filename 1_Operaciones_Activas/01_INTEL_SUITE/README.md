# 01_INTEL_SUITE

**Dominio de Inteligencia Documental, OSINT y Detección Anti-Mafia**

Este paquete unifica los módulos de extracción de datos, periodismo de investigación forense y análisis de redes de influencia en Substack.

## Submódulos Incluidos
- **`substack-osint-miner/`**: Extractor de grafos de influencia, suscriptores, redes y métricas en Substack.
- **`substack-anti-mafia-extension/`**: Extensión de navegador Chrome para detección de astroturfing y redes coordinadas.
- **`documentary_agent_omega/`**: Agente autónomo redactor de informes documentales.
- **`SUBSTACK/`**: Ontologías y colecciones de datos extraídos.

## Modos de Uso
- Ejecución CLI rápida: `./moskv intel` desde la raíz.
- Extensión: Cargar la carpeta `substack-anti-mafia-extension` en Chrome vía `chrome://extensions` (Modo Desarrollador).
