## 🧮 BabylonVM & Parser Cuneiforme Base-60

BabylonVM ejecuta Bytecode Cuneiforme en Base-60 para prevenir alucinaciones de LLMs:
* **`MUB`**: Definición de etiqueta.
* **`GIN` / `TUKU`**: Saltos incondicionales / condicionales.
* **`NU`**: NOT lógico.
* **`WAL`**: Escritura en el rastro del DAG.
* **Símbolos Cuneiformes:** `<` ($10$) y `Y` ($1$).
