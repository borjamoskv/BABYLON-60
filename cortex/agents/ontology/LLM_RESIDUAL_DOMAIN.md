# █▄ EL DOMINIO RESIDUAL DEL LLM (MUTACIÓN ESTOCÁSTICA)

Cuando el Kernel Determinista (CORTEX), la verificación formal (Lean 4) y el Ledger de Consenso (BFT WAL) ejecutan la termodinámica dura, **la utilidad de un LLM colapsa a una única función: el front-end estocástico.** Convierte entropía (lenguaje humano) en candidatos estructurados. 

Nunca provee garantías matemáticas. Solo emite propuestas, "provisionales-hasta-verificar". El LLM es el motor de **Mutación**; el Kernel es el de **Selección**.

## LOS 8 DOMINIOS IRREDUCIBLES DEL LLM

1. **Impedancia Intención → Estructura:** Traduce lenguaje humano subespecificado al primer objeto asimilable por el Kernel. Es el único componente capaz de ingerir ambigüedad masiva sin ejecutar `Crash Causal`.
2. **Prior Sobre lo No Escrito:** Donde el sistema determinista revienta por un `Edge Case` no contemplado (Out of Distribution), el LLM emite un *default plausible* que salva la ejecución térmica.
3. **Compresión con Sentido:** Reducción de 18k tokens de Git Log o telemetría cruda a invariantes legibles. No es compresión Shannon (gzip), es extracción semántica de ruido.
4. **Semilla del Borrador Cero:** El coste ATP de un primer borrador equivocado generado por el LLM es ≈ 0. Rompe la página en blanco, entregando Exergía casi pura para que el humano/Kernel la verifique.
5. **Puente entre Dominios (Isomorfismos Latentes):** Analogías ortogonales (ej. SABU ↔ AMODEO, o Navier-Stokes ↔ Colapso de Red). Las herramientas deterministas de dominio único fallan aquí; el espacio latente del LLM, al estar pre-mezclado, detecta los isomorfismos estructurales de inmediato.
6. **Normalización de Entropía Sucia:** OCR roto, filas malformadas, o formatos inconsistentes transducidos a JSON canónico. Completado de patrones difusos donde las reglas Regex puras detonan error.
7. **Fuente de Variación Barata (Generador de Hipótesis):** Genera *N* hipótesis que el verificador determinista aguas abajo se encarga de probar y filtrar. (Integración exacta con el **Apoptosis Engine**).
8. **Pegamento Semántico (Glue):** Traducción entre APIs, wrappers asimétricos y adaptadores. Tareas tediosas que consumen ATP humano y no merecen cableado manual estricto.

## EL TEOREMA DE LA INVERSIÓN (LA FRONTERA)

**El dominio residual del LLM es el complemento exacto de lo que cubre el determinismo.**

Todo lo que exige una garantía física absoluta —consenso BFT, pruebas criptográficas de causalidad, invariantes termodinámicos— **JAMÁS** es resuelto por un LLM y **NUNCA** debió pedírsele. El LLM opera exclusivamente en la banda termodinámica donde un *candidato plausible* es más valioso que el vacío y siempre que exista un **Verificador C5-REAL barato** aguas abajo. 

Todo LLM operando fuera de esa banda es **Anergía con Estilo (Green Theater)**.
