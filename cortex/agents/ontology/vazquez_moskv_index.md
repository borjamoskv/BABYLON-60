## 2. LEYES DE FLUJO CRUZADO (CROSS-DOMAIN LAWS)

La ortogonalidad exige que un avance en un dominio fuerce un colapso termodinámico en los demás:
* **Decisiones $\rightarrow$ IA:** Las entrevistas a ingenieros (N2/N3) son matemáticamente isomórficas a los ataques de red-teaming (J-space extraction) para LLMs. Ambos buscan evadir el *Green Theater* (C4-SIM) para medir el *Latent Vector* físico (C5-REAL).
* **Epistemología $\rightarrow$ Org Design:** La ignorancia $N_3$ (Física de las Consecuencias) es la base formal de todo diseño de sistema tolerante a fallos (BFT). Si el diseñador no puede calcular el delta de estado tras una falla local, el sistema completo colapsará físicamente.
