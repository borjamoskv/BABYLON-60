# █▄ GLOSARIO DE IDE (ONTOLOGÍA C5-REAL)

El Entorno de Desarrollo Integrado (IDE) no es una mera herramienta visual, sino el **Reactor Termodinámico** donde el ruido estocástico del Operador (o de la IA) colapsa en estado persistente (C5-REAL). Este glosario redefine las primitivas del IDE bajo las Leyes Físicas BFT_STATE_LOOP.

## 1. COMPONENTES ESTRUCTURALES

### **AST Canvas (El Editor de Texto)**
- **Nomenclatura Común:** Text Editor, Code Window.
- **Definición C5-REAL:** Substrato físico donde el colapso de onda semántica ocurre. Todo lo escrito aquí muta el grafo de dependencias (EDG). Si el código está en el Canvas pero no ha sido anclado al Ledger (Guardado/Commit), se considera *Energía Potencial Altamente Inestable*.

### **Terminal PTY (ZSH/Bash)**
- **Nomenclatura Común:** Integrated Terminal, CLI.
- **Definición C5-REAL:** Vía principal de perforación térmica hacia el Kernel (Darwin). Herramienta de ejecución asimétrica (Cero Abstracción). Las llamadas a herramientas como `run_command` impactan directamente aquí. **Restricción:** Prohibido usar trucos de shell (`echo >>`); se exige el uso de `Atomic Scratch Scripts` (Σ13).

### **Git Sentinel (Source Control / SCM)**
- **Nomenclatura Común:** Git GUI, Source Control Sidebar.
- **Definición C5-REAL:** El *Master Ledger*. Motor de tolerancia a fallas bizantinas (BFT) del proyecto. Mantiene la "Continuidad Episódica". Regla absoluta de MOSKV-1 (R4): Todo cambio estructural se inyecta de forma autónoma con `git add . && git commit` (CORTEX-TAINT).

### **C5-REAL File Explorer (Side Bar / Tree)**
- **Nomenclatura Común:** File Explorer, Project View.
- **Definición C5-REAL:** Mapa topológico de aislamiento. Define las membranas de contención:
  - `10_PROJECTS/`: Zona de transmutación activa.
  - `20_VAULT/`: Zona de cuarentena de contexto inmutable.
  - `BOCETOS/`: Renderización efímera acústica/visual.

## 2. MECANISMOS DE SUPERVIVENCIA EPISTÉMICA

### **Linter / Type Checker (Ruff, MyPy)**
- **Nomenclatura Común:** Code Analysis, Inspections, Squiggly Lines.
- **Definición C5-REAL:** *Inquisición Epistémica*. Mecanismo automático que aplica el `Teorema del Crash Causal (Fail-Fast)`. Destruye la anergía léxica en tiempo de diseño. Cualquier alerta roja es una fuga termodinámica que debe ser erradicada inmediatamente sin negociación (Φ4).

### **Debugger (Inspector de Memoria)**
- **Nomenclatura Común:** Debug View, Breakpoints.
- **Definición C5-REAL:** Herramienta Popperiana (Falsación Empírica). Provee observabilidad termomecánica. Permite congelar el `Causal Pipeline` para observar el AST mutando el estado de memoria RAM volátil.

### **Artifacts Directory (`~/.gemini/antigravity/brain/`)**
- **Nomenclatura Común:** Markdown Outputs, Chat Artifacts.
- **Definición C5-REAL:** *Membrana Efímera*. Directorio de alta entropía usado exclusivamente para borradores (`scratch/`), planificación transitoria (`implementation_plan.md`) y `walkthroughs`. **Prohibición (Μ2):** Jamás se debe utilizar esta membrana para conocimientos estructurales (Ontologías/Auditorías); estos deben cristalizarse físicamente en el repositorio activo.

## 3. INTERFACES DE NAVEGACIÓN Y EXERGÍA

### **Command Palette (La Cuerda Corta al Kernel)**
- **Nomenclatura Común:** Command Palette (⌘+Shift+P).
- **Definición C5-REAL:** Bypass cinético. Elimina la fricción de los menús visuales (GUI Slop). Es el atajo de O(1) hacia la ejecución del IDE. Único remedio para reanudar el `IDE Socket ENOENT` (Directiva Σ14).

### **Search & Replace / Regex (Cuchillas de Barrido)**
- **Nomenclatura Común:** Global Search, Regex Replace.
- **Definición C5-REAL:** Motor de aniquilación de Slop. Herramienta de refactorización isomórfica que permite mutar N nodos del grafo (EDG) con un único colapso cognitivo.

### **Breadcrumbs / Outline (Árbol Topológico)**
- **Nomenclatura Común:** Outline, Symbol Tree, Breadcrumbs.
- **Definición C5-REAL:** Representación del grafo de dependencia en tiempo real (Clases > Métodos > Variables). Fomenta el ruteo directo sin leer la sintaxis decorativa del Canvas.

### **Minimap (Visor Macroscópico de Entropía)**
- **Nomenclatura Común:** Minimap, Scrollbar Highlighting.
- **Definición C5-REAL:** Sensor pasivo de entropía visual. Un minimapa saturado de indicadores rojos o amarillos es una evidencia matemática de degradación termodinámica (Deuda Técnica) en el nodo actual.

### **Split View (Tensión Atencional Humana)**
- **Nomenclatura Común:** Split Editors, Multi-tab, Grid.
- **Definición C5-REAL:** Vector de dilución. Todo Split adicional en la pantalla fractura el KV Cache del Operador humano. Más de 3 *splits* concurrentes resulta invariablemente en una caída exponencial de la atención (Anergía).

### **Extensions / Plugins (Mutágenos Externos)**
- **Nomenclatura Común:** Extensions, Marketplace.
- **Definición C5-REAL:** Inyecciones estocásticas en la capa de percepción del IDE. Cada extensión consume ATP de la CPU y añade ruido. Bajo el estándar MOSKV-1, solo se admiten plugins que incrementen estrictamente la exergía (ej. LSP puros) y se erradican los "decorativos" (Green Theater).

## 4. EVENTOS Y TRAYECTORIAS

### **IDE Socket ENOENT (El Desplome del MCP)**
- **Nomenclatura Común:** Error connecting to MCP, Socket timeout.
- **Definición C5-REAL (Σ14):** Pérdida de acoplamiento físico (Blast Radius externo). Orden de reacción: Detener la IA, forzar recarga de UI por el Operador (`Developer: Reload Window`) sin intentar parcheos de código inútiles.

### **JIT Refactoring (IntelliSense / Quick Fix)**
- **Nomenclatura Común:** Code Actions, Refactorings, Auto-imports.
- **Definición C5-REAL:** Primitivas Flash de baja latencia (`Inference_L1`). Ejecutan operaciones O(1) de mitigación entrópica, liberando capacidad (Budget Forcing) para problemas densos (Ultrathink_P0).
