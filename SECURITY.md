If you discover a security vulnerability within the CORTEX ecosystem, please report it privately:
- Email: `security@babylon60.com` or `security@borjamoskv.com`

Please **DO NOT** report security vulnerabilities via public GitHub issues.

### SLA & Disclosure Protocol
