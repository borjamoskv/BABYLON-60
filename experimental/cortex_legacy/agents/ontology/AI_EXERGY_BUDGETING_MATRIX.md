# █▄ MATRIZ DE PRESUPUESTO EXERGÉTICO (AI TOOLS)

El stack base del Operador (Perplexity Pro, Gemini Pro, Claude Code Max, GitHub Copilot) ya satura las capacidades conversacionales y agénticas de primer nivel. Cualquier inyección adicional de capital debe ir destinada a **abrir vectores ortogonales de ejecución**, no a duplicar capacidades ya existentes.

## 1. ANERGÍA (CAPITAL REDUNDANTE - PROHIBIDO)
Gastar en estas herramientas con el stack actual genera cero retorno (Anergía):
- **Cursor / Windsurf:** Redundante frente a Claude Code Max + Copilot.
- **Midjourney / DALL-E:** Gemini Pro ya integra generación SOTA de imagen/vídeo (Veo/Imagen).
- **Claude Pro:** Ya cubierto por la versión Max / Claude Code.
- **Suscripciones a Modelos Abiertos (Mistral, Llama):** Deben consumirse vía API, no bajo un muro de suscripción.

## 2. INYECCIÓN RECURRENTE (60€/mes)
Si el flujo de capital es mensual, la asignación termodinámica óptima es:

1. **Wispr Flow Pro (~15€):** Elimina el cuello de botella físico (velocidad de tipeo). Hablar es 3x más rápido que escribir. Multiplica el throughput de todo el stack agéntico restante.
2. **ChatGPT Plus (~23€):** Cubre el "Gap" de OpenAI (GPT-5.6, Sora, Deep Research). Otorga redundancia de frontera: cuando el motor de Anthropic falla en razonamiento, se aplica un ataque ortogonal con OpenAI.
3. **VPS (~5€) + n8n self-host:** Instancia 24/7 en la nube para ejecutar agentes durmientes mientras el Operador no está frente a la terminal.
4. **ElevenLabs Starter (~6€):** Capacidad TTS ortogonal, única modalidad no cubierta por texto/visión.

## 3. INYECCIÓN ONE-SHOT (Depósito Único)
Si el capital no es recurrente, las suscripciones son Entropía temporal (mueren al mes). El 100% del capital debe ir a **Créditos API sin caducidad**:

1. **OpenRouter Credits:** Permite ejecutar modelos en batch, automatización masiva y enrutamiento dinámico pay-per-use sin el markup mensual.
2. **fal.ai Credits:** Generación programática de media (Flux, Video) desde scripts (corte directo a la API, sin interfaces conversacionales).
3. **GPU Spot (vast.ai / RunPod):** Acceso crudo a hardware (A100 / RTX 4090) a céntimos la hora para entrenar LoRAs locales o inferencia local pura.

## 4. EXERGÍA LATENTE (COSTE 0€)
El Operador posee capital termodinámico ya pagado que no está extrayendo. Extraerlo debe preceder a cualquier inyección de capital nuevo:
- **Agente Jules (Gemini Pro):** Segundo agente de código asíncrono, puede correr en paralelo a Claude Code.
- **NotebookLM Plus & 5TB (Gemini Pro):** Espacio de conocimiento para RAG local.
- **Créditos API Sonar (Perplexity Pro):** Acceso programático ya incluido en la mensualidad.
- **OpenRouter Free Tier:** Modelos Llama/Mistral gratuitos limitados por RPM. Excelente para tareas de clasificación masiva de baja prioridad.
