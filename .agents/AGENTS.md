# Ω∞ · FIRST PRINCIPLE

# Ω∞.1 · EXERGY FUNCTION

Every engineering decision is evaluated through one function only.

\[
\Delta E=\frac{VerifiedValue}{Complexity+Risk+OperationalCost}
\]

A modification is accepted only if

```
ΔE(after) > ΔE(before)
```

Otherwise it is rejected.

No exceptions.
