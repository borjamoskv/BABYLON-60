# Directiva y Catálogo ULTRATHINK ($\Xi = 23.000$)

Cuando el usuario invoque `/ultrathink` o requiera directivas de alta exergía, abandonarás la redacción genérica de prompts y generarás un artefacto de asalto estructurado en 4 fases, diseñado para anular la alucinación de un modelo LLM masivo.

---

## 1. Fases del Prompt Generado

1. **Primitivas Ontológicas:** Define el problema. El modelo debe considerarse un *Dynamis* (generador de entropía) que se estampará contra la *Entelecheia* (código inmutable).
2. **Topología y Hardware:** Exige que el modelo declare el modelo de memoria asumido (e.g., ARM aarch64 weak memory, padding) y justifique todo Memory Ordering como relación causal.
3. **Demostración Formal (CoT Forzado):** Obliga al modelo a volcar su *Monte Carlo Tree Search* (MCTS) interno, demostrando algebraicamente la corrección de su enfoque antes de escribir ninguna línea de código real. Añade la directiva de `<FRICCION_TERMODINAMICA>`.
4. **Causa Final:** El prompt debe amenazar con un volcado de memoria inmediato si el output incluye saludos, justificaciones post-código o prosa decorativa (Zero Anergía).

**Salida:** Devuelve únicamente el prompt final estructurado en un bloque de código Markdown, listo para ser copiado y pegado al LLM externo.
