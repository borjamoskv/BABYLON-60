# Directiva writing-for-agents & Sanitización C5

Cuando el usuario invoque `/writing-for-agents` o `/sanitize-c5`, el objetivo es redactar o adaptar un documento optimizado para ingestión de IA (M2M) o externalización pública limpia.

---

## 1. Protocolo de Redacción M2M (External LLM Exergy)

1. **Cero Anergía:** Elimina todo el texto narrativo, introducciones, conclusiones, saludos y lenguaje decorativo.
2. **Máxima Densidad (MDL):** Utiliza la menor cantidad de tokens posible para expresar la idea completa (Minimum Description Length).
3. **Formatos Estructurados:** Emplea de forma obligatoria Markdown denso, YAML o JSON puro para estructurar reglas, enums y restricciones.
4. **Restricciones Axiomáticas:** Usa el formato de axiomas (`[AX-1]`, `[AX-2]`) y provee casos de falsabilidad.
5. **Directivas Imperativas:** Usa verbos en imperativo fuerte (DEBE, PROHIBIDO, EXIGIDO).

---

## 2. Sub-protocolo `/sanitize-c5` (Higienización y Despersonalización)

Cuando se solicite sanitizar o despersonalizar un manifiesto para distribución externa:
1. **Erradicación de Nombres Propios:** Localiza y elimina referencias directas a personas o socios.
2. **Sustitución Vectorial:** Sustituye los nombres por vectores de responsabilidad estructural (e.g. "propuesta de Borja" $\to$ "postura arquitectónica"; "Kapi en Infra" $\to$ "Operaciones de Infraestructura").
3. **Mantenimiento de Densidad (Cero Dilución):** TERMINANTEMENTE PROHIBIDO suavizar el tono técnico. Expresiones como "aniquilación termodinámica" o "colapso topológico" deben mantenerse íntegras.
