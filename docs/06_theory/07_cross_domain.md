# Analogías entre lógica, lenguaje y cognición

Revisión científica: 2026-10-24. Estatus: **Ensayo-con-analogias-no-demostradas**. El sello histórico de verificación y el axioma genérico de validez documental no acreditaban el contenido. [Alcance y evidencia de la revisión](AUDIT_SCIENTIFIC_STATUS_2026.md).

## 1. Estatus de las correspondencias

Se conservan como preguntas filosóficas las comparaciones entre lenguaje, aprendizaje y sistemas formales. Se retiran como «isomorfismos rigurosos»: no se definían objetos, transformaciones biyectivas ni leyes preservadas. Un parecido narrativo no demuestra una equivalencia matemática.

| Comparación histórica | Corrección |
| --- | --- |
| Skinner = primer orden; Chomsky = segundo orden | Analogía, no identificación de teorías formales. No se ha demostrado que una teoría lingüística sea categórica o tenga la propiedad de compacidad. |
| Pobreza del estímulo = incompletitud | Son problemas distintos. Incompletitud trata demostrabilidad bajo hipótesis precisas; no-identificabilidad de una gramática desde datos requiere un modelo de aprendizaje. |
| LLM = modelo no estándar de PA/Q | No se aporta estructura aritmética que satisfaga los axiomas. Ser diferente del cerebro no hace a un transformer un modelo no estándar en sentido lógico. |
| Comprensión de lenguaje = paradoja de Skolem | Interpretación filosófica pendiente de operacionalizar; no es consecuencia del teorema Löwenheim–Skolem. |

No se sostiene que los LLMs satisfagan todas las restricciones observables del lenguaje. Eso requeriría definirlas y evaluarlas, y no se deduce de fluidez ni de algunos tests.

## 2. Argumentos gödelianos sobre la mente

El argumento de Lucas/Penrose necesita justificar qué sistema formal representa al agente, qué corrección se le atribuye y por qué puede reconocer la sentencia pertinente. Gödel y Löb por sí solos no prueban ni refutan que una mente sea computable. La crítica debe identificar esos supuestos; no puede sustituirse por una proclamación de imposibilidad física.

Fuente primaria para el argumento filosófico: [J. R. Lucas, *Minds, Machines and Gödel* (1961)](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/727219EDEB5DD3679E56CF3D335C90C1/S0031819100057983a.pdf/minds_machines_and_godel1.pdf). Sus conclusiones son objeto de discusión, no certificados del sistema.

## 3. Referencia e interpretación

El argumento modeloteórico de Putnam es una tesis filosófica sobre referencia e interpretación. No demuestra que todo significado sea de segundo orden ni que un software tenga comprensión o carezca de ella. No se infiere una ontología universal para BABYLON-60.

Se retiran el diagrama con aristas «Isomorphic» y el axioma `document_epistemic_validity`. El documento no contiene una prueba formal de equivalencia entre lógica y cognición. Referencias históricas: Chomsky (1959), *A Review of B. F. Skinner’s Verbal Behavior*; Putnam (1980), *Models and Reality*.
