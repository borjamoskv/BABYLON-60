# Tétrada C5-REAL: metáforas y separación de dominios

Revisión científica: 2026-10-24. Estatus: **Marco-interpretativo-sin-equivalencia-fisica**. El sello histórico de verificación y el axioma genérico de validez documental no acreditaban el contenido. [Alcance y evidencia de la revisión](AUDIT_SCIENTIFIC_STATUS_2026.md).

## 1. Estatus del marco

Q (cuántica), S (entropía), A (atractores) y Ω (singularidad) se conservan como etiquetas interpretativas opcionales. No forman una teoría física del runtime ni una prueba de gobernanza. Se retiran «C6-ABSOLUTE», «cristal sellado» y la afirmación de bisimulación jurídico-física sin brecha.

| Etiqueta | Interpretación posible | Equivalencia retirada |
| --- | --- | --- |
| Q | Importancia del orden de operaciones concurrentes | No conmutatividad de software no demuestra mecánica cuántica ni información cuántica de Fisher infinita. |
| S | Coste de recursos, representación y retención | Un contador o una escritura no implica borrar exactamente 64 bits equiprobables ni disipar esa cota de Landauer. |
| A | Reintentos, estados de error y estabilidad de protocolos | Un Seqlock no aporta automáticamente una dinámica diferenciable con div(F) < 0 ni progreso garantizado para lectores. |
| Ω | Políticas de autoridad, evidencias y cierre | La entropía de agujeros negros no limita el volumen de auditoría legal de software ni hace isomorfos contrato y binario. |

## 2. Correcciones técnicas

La alineación a 64 B de una estructura no demuestra que toda arquitectura tenga esa línea de caché, una sola transacción de coherencia, ausencia de false sharing o disipación mínima. Validar barreras y atomicidad requiere el modelo de memoria y los accesos completos; una lista de fences no constituye esa prueba.

Las cifras de secuencia y campos de [BabylonTrace.lean](../../proof/lean/BabylonTrace.lean) modelan una parte de un protocolo. No se ha demostrado aquí bisimulación de todas las trazas Rust con el modelo ni exclusión de lecturas físicas fragmentadas. Un test de tipos tampoco mide información de Fisher.

La base 60 tiene más divisores que 10; eso no elimina todo truncamiento. En representación finita en base b, una fracción reducida termina solo cuando los factores primos de su denominador dividen b: 1/7 no termina en base 60. En decimal 1/4 sí termina, corrigiendo el ejemplo original. Esto es aritmética de representación, no supresión universal de entropía.

## 3. Física, biología y derecho

Landauer requiere un modelo de borrado físico; no se aplica automáticamente a cada incremento de Seqlock. Mover o hashear información no garantiza calor cero. El [compendio corregido](c5_thermodynamic_invariants_compendium.md) fija unidades y alcance.

Una fórmula de energía libre variacional necesita variables aleatorias, modelo generativo y distribución aproximante definidos. Para un modelo apropiado puede escribirse F(q) = KL(q(z) || p(z|y)) − ln p(y); usar «atención» y «estado del sistema» sin esas definiciones no produce una medida de burnout. Se retira la garantía fisiológica y de protección del tejido humano.

El umbral f < n/3 pertenece a modelos de consenso concretos, con hipótesis de comunicación, fallos y sincronía; no surge de llamar «atractor» al protocolo. Del mismo modo, una firma P-256 no implica validación de la identidad biológica del operador en todos los recorridos ni cumplimiento legal. La [supervisión humana](https://ai-act-service-desk.ec.europa.eu/en/ai-act/article-14) no se deduce de una analogía holográfica.

## 4. Obligaciones frente a observaciones

Los contratos de autorización y fallo del proyecto siguen vigentes. No se afirma que se hayan ejecutado ni medido todos sus mecanismos. Las expresiones «apoptosis» y «singularidad» no autorizan apagados, liberación de recursos ni acciones en el sistema del operador.
