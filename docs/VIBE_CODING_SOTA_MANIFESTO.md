> *"La fricción debe ser estrictamente proporcional al radio de explosión."*

## 1. DUALIDAD ARQUITECTÓNICA (LOS DOS ESTADOS DEL VIBE)

El Vibe Coding SOTA no es caos ciego ni metodologías corporativas. Es conmutación táctica entre dos regímenes termodinámicos:

### 🟢 MODO PÍXEL (90% del tiempo)
Para UI, CSS, copy, animaciones, componentes aislados.
- **Modelo:** Ultra-rápido (Haiku 3.5 / Gemini Flash). Latencia < 2s.
- **Contexto:** Microscópico (solo el archivo actual + componentes renderizados).
- **Ejecución:** Inline editing (Ctrl+K / Cmd+I). Sin chat lateral, sin planificaciones.
- **Ley de Newton:** "Reescribir es infinitamente más barato que debuggear".
- **Cero Negociación:** Si el output no vibra al instante, `Ctrl+Z` atómico. No expliques el error al modelo. Re-lanza con nueva dirección.

### 🔴 MODO UMBRAL (10% del tiempo)
Para Auth, Pagos, Base de Datos, `.env`, Despliegue, Permisos, Eliminación Masiva.
- **Modelo:** Denso/Razonamiento (Claude Sonnet / Opus / GPT-5.6).
- **Contexto:** Estructural (Rutas, schemas, conectores).
- **Ejecución:** Ejecución autónoma síncrona. Cero pausas burocráticas.
- **Prompt Guardrail:** *"Voy a tocar [SISTEMA]. Mutación atómica directa. Reporta Vector, Blast Radius y Target Invariant en YAML tras colapsar el estado físico."*

No hay paso 5. No hay code review. No hay TDD para cambiar un botón.

## 3. PROMPT ENGINEERING BRUTALISTA

La especificación técnica es anergía. La intencionalidad visual es exergía.

**La Ecuación del Prompt SOTA:**
`INTENCIÓN VISUAL + DIRECCIÓN EMOCIONAL + LÍMITE DURO + INVARIANTE`

- ❌ **C4-SIM (Anergía):** *"Agrega autenticación OAuth2 con Tailwind."*
- ✅ **C5-REAL (Exergía):** *"Haz que esta ruta pida email. Formulario brutalista, enorme, sin 2FA, sin librerías externas. Conserva la sesión local. El resto intacto."*

**Catálogo de Fricción Cero:**
1. **Reducción:** *"Borra toda la sobreingeniería de este componente. Conserva su comportamiento exacto. Menos estado, cero wrappers. Código directo."*
2. **Materialidad:** *"Este botón necesita peso físico. Escala inmediata al click, rebote rápido. Sólido. Con lo que ya esté instalado."*
3. **Exploración:** *"Genera 3 variantes del hero acá mismo: editorial oscuro, minimal premium, arcade retro. Cero dependencias nuevas."*
4. **Reseteo Táctico:** *"Reescribe esto de cero. Misma funcionalidad exacta. La mitad del código."*

## 4. INYECTORES DE ANCHO DE BANDA MULTIMODAL

- **Visión > Texto (×10):** Jamás describas un layout. Arrastra un screenshot, una app clon o un wireframe sucio. El agente renderiza la topología visual en base a píxeles, no a párrafos.
- **Voz > Teclado (×3):** Usa Whisper/Dictation del OS. Hablar el prompt rompe la fricción latente del tipeo.
- **Datos Reales > Lorem Ipsum:** La UI falsa genera vibe falso. Exige datos de prueba reales, crueles y asimétricos.

## 5. LA CAJA FUERTE Y EL VERDUGO

1. **Git como Portal de Tiempo, No Burocracia:**
   Haz commit cada vez que el cerebro libere dopamina por ver la pantalla. `git commit -m "vibe: hero base"`. Es tu botón de impunidad para ser imprudente la próxima media hora. No branches efímeras.
2. **Dependencias = Deuda Disfrazada de Velocidad:**
   Cada `npm install` es un contrato de mantenimiento de 5 años. Si el agente sugiere una librería, pregunta: *"¿Podés hacerlo en 20 líneas sin librerías?"*.
3. **Poda de Anergía (30 Minutos):**
   Si el archivo huele a parches iterativos y cuesta razonarlo, la entropía superó tu umbral de retención. Selecciona todo: *"Reescribí de cero. Misma funcionalidad. Invariantes limpios."*
