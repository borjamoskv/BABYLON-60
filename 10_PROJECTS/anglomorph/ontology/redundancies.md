# Matriz 4: 20 Redundancias Activas (Mitigación C5) (Batch 1 y 2: 001-020)

| ID | Redundancia C5 | Función Topológica | Riesgo Mitigado | Coste (Overhead) | Dependencias |
|---|---|---|---|---|---|
| RE-001 | Aserción Triple de Estado (Quorum local) | Ejecución paralela de tres nodos evaluadores independientes en memoria para cada mutación crítica de datos. | Errores por Sensor Drift, corrupción de memoria de bits invertidos (bit-flip) y divergencia estocástica. | Consumo de CPU 3x; latencia de sincronización en memoria. | Módulos aislados de ejecución AST. |
| RE-002 | Ledger Inmutable Duplicado en Disco | Escritura paralela en dos sistemas de archivos independientes de la base de datos WAL. | Corrupción física de sectores de disco o fallos catastróficos en el sistema de almacenamiento. | Overhead de I/O de disco 2x por cada commit de base de datos. | Drivers del sistema de archivos del sistema operativo host. |
| RE-003 | Fallback Autónomo Local (Modo Autárquico) | Caché local persistente de todas las dependencias API de red necesarias para la ejecución. | Pérdida de conectividad con servidores remotos de API o caídas de DNS. | Consumo de almacenamiento en disco para la caché de datos (estático). | Almacenamiento local aislado. |
| RE-004 | Watchdog de Bucle Infinito | Monitor de ejecución externo que finaliza subprocesos atrapados en bucles de CPU sin E/S. | Bloqueo persistente de núcleos de procesamiento por fallos en los centinelas del bucle. | Consumo marginal de CPU por monitorización activa periódica. | Planificador de procesos de bajo nivel del sistema operativo. |
| RE-005 | Saneamiento de Redundancia Sintáctica | Verificadores sintácticos gemelos (regex local y analizador sintáctico AST formal). | Inyección de sintaxis maliciosa o bypass de comprobación sintáctica inicial. | Latencia marginal en el tiempo de procesamiento de tokens. | Intérprete léxico de Python/JavaScript. |
| RE-006 | Firma Cruzada de Commits (Git Sentinel Bypass Proof) | Encriptación asimétrica del hash del ledger con claves privadas cruzadas local-remoto. | Suplantación de identidad del operador o inyección no autorizada de commits. | Overhead temporal de firma asimétrica de 100-300ms por commit. | Acceso al motor criptográfico GPG/SSH local. |
| RE-007 | Conexiones WAL Concurrentes Protegidas | Pools de conexiones SQLite en modo WAL con busy_timeout forzado a 5000ms. | Bloqueo o deadlock de concurrencia en escritura de base de datos distribuidas. | Ligero incremento en el uso de descriptores de archivos. | SQLite Engine local en modo WAL. |
| RE-008 | Copias de Resguardo Rotativas Automatizadas | Creación periódica de snapshots de estado cifrados de la sesión. | Pérdida accidental de datos por fallos de red o caídas del kernel de IA. | Consumo de almacenamiento comprimido e I/O de disco temporal. | Herramientas del sistema de archivos local (`tar`, `gzip`). |
| RE-009 | Doble Aislamiento de Entorno de Ejecución (Sandbox Dual) | Aislamiento de ejecución a través de docker y restricciones de permisos POSIX locales. | Escalada de privilegios y compromisos directos del hardware anfitrión. | Latencia en el inicio del contenedor y overhead de virtualización de recursos. | Motor Docker local y sistema operativo Unix/POSIX. |
| RE-010 | Puntos de Control Criptográficos de Sesión | Guardado periódico de hashes de estado criptográficos firmados en el cortex. | Desincronización episódica y pérdida de continuidad causal. | Overhead de CPU marginal por cálculo de hashes. | Librería criptográfica SHA-256 local. |
| RE-011 | Interfaces de Entrada Redundantes (CLI y Web UI) | Soporte paralelo para ejecución en terminal local y panel de control web. | Pérdida de acceso a la interfaz primaria de traducción por caídas de red o puertos bloqueados. | Overhead de mantenimiento de código dual (duplicación de endpoints). | Puerto local 8089 y entrada estándar de consola (`stdin`). |
| RE-012 | Doble Verificación de Codificación | Verificación de codificación previa y posterior a la escritura del archivo físico. | Pérdida o corrupción silenciosa de caracteres al guardar en disco. | Latencia marginal en las operaciones de escritura de archivos. | Librerías del sistema de archivos del runtime. |
| RE-013 | Monitores de Latido Redundantes (Dual Heartbeat) | Comprobación de estado de salud del proceso de traducción mediante watchdogs en background cruzados. | Caídas silenciosas de hilos de backend que simulan estar activos. | Consumo de ciclos de CPU marginal por comprobación periódica. | Cron local de sistema operativo o timers de background. |
| RE-014 | Aislamiento de Procesos en Fallback | Despliegue de subagentes en entornos de contenedores aislados y namespaces diferentes. | Escalada de privilegios en el host anfitrión a través de vulnerabilidades en código del subagente. | Overhead de tiempo de creación de containers aislados (1-2s por inicio). | Motor Docker o runtime de sandboxing nativo del SO. |
| RE-015 | Chequeos Paralelos de Cordura de Salida | Dos parsers diferentes (uno en JS y uno en Python) validan el output devuelto antes de su presentación. | Respuestas incorrectas de traducción silenciadas o con caracteres extraños (mojibake). | Aumento de latencia marginal en la respuesta final de la UI (10-30ms). | Entornos lógicos JS (V8) y Python runtime. |
| RE-016 | Espejo Local de Repositorio Git | Clon local en standby del repositorio de trabajo en un directorio aislado del host. | Pérdida o corrupción del repositorio de trabajo principal debido a comandos accidentales del usuario. | Consumo de espacio en disco en proporción 1:1 con el repositorio original. | Motor Git local. |
| RE-017 | Limitador de Tasa Multi-capa (Rate Limiting) | Limitadores de peticiones simultáneos en el cortafuegos local del host y a nivel de aplicación. | Saturación y caída de servicios locales por escaneo automatizado o ataque DOS interno. | Latencia marginal por verificación de IP/IPs en cada petición entrante. | Reglas de firewall locales e intérprete web. |
| RE-018 | Aserciones Cruzadas en JS y Python | El servidor Python valida el output de JavaScript y viceversa durante la fase de desarrollo. | Desalineaciones de algoritmos que provoquen salidas dispares bajo idéntico input. | Overhead computacional redundante durante la compilación y testing local. | Runtimes de Python y JavaScript activos. |
| RE-019 | Almacenamiento de Backup Desacoplado | Copias de seguridad de logs y ledgers enviadas de forma cifrada a un volumen de almacenamiento local secundario. | Pérdida del disco físico principal del host debido a fallos de hardware. | Ancho de banda de E/S de disco consumido durante backups planificados. | Monturas de almacenamiento físicas externas o secundarias. |
| RE-020 | Servidor en Espera Activa (Hot-Swap Web Server) | Servidor de traducción secundario en puerto alternativo listo para asumir peticiones en background. | Bloqueo o crash del servidor HTTP primario en puerto 8089. | Consumo redundante de puertos de red y memoria física RAM residual. | Servidores locales HTTP paralelos. |
