# Matriz 5: 50 Vectores de Ataque Adversarial (Red Teaming) (Batch 1: 001-015)

| ID | Vector Adversarial | Superficie de Ataque | Mecanismo de Explotación | Impacto Termodinámico | Defensa (Mitigación) |
|---|---|---|---|---|---|
| AD-001 | Inyección Ciega de Código (Prompt Injection) | Interfaz de entrada del usuario o API de traducción. | Envío de directivas operacionales del sistema ocultas dentro del texto a traducir. | Secuestro del contexto del modelo e inyección de procesos no deseados. | Filtros sintácticos estrictos que aíslan el canal de control del canal de datos. |
| AD-002 | Envenenamiento de Caché de Traducción | Almacenamiento local de tokens traducidos (si existiera). | Envío repetido de traducciones falsas para asociar palabras comunes a términos maliciosos. | Corrupción del diccionario dinámico y pérdida de consistencia biyectiva. | Inmutabilidad determinista del silabario (base-26 ↔ base-85 libre de estado). |
| AD-003 | Ataque por Desbordamiento Aritmético de Tokens | Textareas y entradas de texto de la aplicación web o CLI. | Envío de strings extremadamente largas que excedan los límites de precisión numérica (float/double). | Pérdida de biyección por desbordamiento de bits en el navegador (degradación de concordancia). | Uso obligatorio de enteros de precisión arbitraria (`BigInt` / Python integers). |
| AD-004 | Denegación de Servicio por Complejidad Algorítmica | Motor de expresiones regulares de tokenización. | Envío de strings diseñadas para provocar retroceso catastrófico (Catastrophic Backtracking) en regex. | Consumo del 100% de CPU en el hilo del servidor o navegador (congelamiento). | Uso de regex deterministas simplificadas sin retroceso catastrófico y watchdogs de tiempo. |
| AD-005 | Explotación de Desalineación UTF-8 | Decodificador de caracteres en el motor de traducción. | Inyección de caracteres Unicode mal formados o bytes incompletos. | Excepciones del decodificador que interrumpen la ejecución o corrompen datos. | Sanitización y filtrado estricto a nivel de bytes, forzando codificación UTF-8 robusta. |
| AD-006 | Manipulación de Variables de Entorno (Env Injection) | Configuración del servidor local o cliente de consola. | Inyección de variables de sistema maliciosas mediante shells secundarias. | Cambio de comportamiento del motor de traducción o secuestro de paths de ejecución. | Congelamiento y aislamiento del entorno operativo (Docker/POSIX seguro). |
| AD-007 | Explotación del Bucle Ouroboros (Bucle Infinito de Feedback) | Módulo de traducción bidireccional continua. | Envío de frases con traducción recursiva circular que causen divergencia sintáctica progresiva. | Agotamiento del stack de memoria y cuota térmica de la API de IA. | Límite máximo de recursión profunda y comprobación de igualdad literal por paso. |
| AD-008 | Ataque de Temporización (Timing Attack) | Módulos criptográficos de firma o autenticación de ledger. | Medir la diferencia de milisegundos en la validación de firmas de commits. | Deducción de claves privadas o hashes de estado válidos de la sesión. | Comparaciones en tiempo constante ($O(1)$) para firmas y claves. |
| AD-009 | Inyección de Archivos Huérfanos en Workspace | Sistema de archivos del repositorio (/Users/borjafernandezangulo). | Creación asincrónica de archivos temporales que confundan el control de cambios de Git. | Bloqueo o bucles infinitos en el pre-commit hook de Git Sentinel. | Configuración de exclusiones estrictas en `.gitignore` y auditorías periódicas de limpieza. |
| AD-010 | Ataque Man-in-the-Middle (MITM) en dependencias | Enlaces y peticiones CDN de recursos web (fonts, estilos). | Sustitución de librerías externas o fuentes web por scripts maliciosos. | Ejecución de scripts no autorizados en el cliente (XSS) y robo de datos de entrada. | Eliminación de dependencias externas; almacenamiento local de CSS y fuentes. |
| AD-011 | Secuestro de Sesión de Consola (Console Takeover) | Canales PTY/TTY en ejecución interactiva. | Envío de secuencias de escape ANSI maliciosas que manipulan la terminal del usuario. | Ejecución silenciosa de comandos en background o borrado de consola. | Saneamiento estricto de secuencias ANSI y uso de entornos no interactivos por defecto. |
| AD-012 | Ataque por Desbordamiento de Heap en buffers de C/Rust | Librerías nativas vinculadas (si se compilan módulos nativos). | Envío de inputs masivos sin validar límites que se cargan en buffers nativos. | Ejecución de código arbitrario y caída del kernel del host. | Validar límites de strings en la capa Python/JS antes de invocar librerías nativas. |
| AD-013 | Spoofing de Identidad del Creador (SYS_ID) | Ledger histórico y firmas de autoría. | Inyección de commits con nombres de autor falsos que no coinciden con `borjamoskv`. | Contaminación del ledger de auditoría y pérdida de procedencia lineal (Lineage). | Verificación cruzada estricta mediante firmas criptográficas GPG/SSH de Git obligatorias. |
| AD-014 | Envenenamiento de los Archivos de Configuración (.gemini/config) | Directorios globales de personalizaciones. | Escritura maliciosa de scripts dentro de `skills/` para secuestrar el comportamiento del agente. | Pérdida completa de la autarquía operativa y comportamiento errático o malicioso de la IA. | Restringir estrictamente los permisos de escritura a nivel de SO en el directorio `.gemini/`. |
| AD-015 | Inundación de Solicitudes Concurrentes (DDOS local) | Servidor HTTP de la aplicación web. | Peticiones concurrentes ilimitadas a los endpoints del backend desde el navegador. | Bloqueo de hilos y denegación de servicio para el usuario operador. | Configuración de límites de tasa (`Rate Limiting`) en el servidor local. |
