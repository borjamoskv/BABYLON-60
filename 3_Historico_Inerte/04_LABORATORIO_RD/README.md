# 04_LABORATORIO_RD

**Laboratorio R&D, Compilador Moskv84, Simuladores y Utilidades de Alto Rendimiento**

Espacio reservado para la investigación pura, prueba de teoremas y componentes de bajo nivel en Rust y C++.

## Submódulos Incluidos
- **`moskv84-compiler/` & `moskv-85/`**: Compilador propio en Rust y Máquina Virtual/Runtime para el lenguaje simbólico.
- **`moskv-1-apex/`**: Simulador matemático y entorno de prueba termodinámico.
- **`strike-rs/`**: Motor de ejecución rápida en Rust para transducción categórica.
- **`moskv_rpc_cartel/`**: Protocolo de comunicación RPC distribuido.

## Modos de Uso
- Compilador Moskv84: `cd 1_Operaciones_Activas/04_LABORATORIO_RD/moskv84-compiler && cargo run`
- Strike-RS check: `cd 1_Operaciones_Activas/04_LABORATORIO_RD/strike-rs && cargo check`
