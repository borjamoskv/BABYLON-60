# Firedancer VM Forensic Verification Report (OUROBOROS-FD-VM-01/02)

## 1. Executive Summary
This report documents the formal verification of two critical sandbox bypass vulnerabilities in the Firedancer VM (v1.0-audit). The vulnerabilities allow for out-of-bounds (OOB) memory access and integer underflow in host address resolution, leading to arbitrary memory read/write and sandbox escape.

**Vulnerabilities:**
- **OUROBOROS-FD-VM-02**: Sandbox OOB Leak via Unchecked Region Index.
- **OUROBOROS-FD-VM-01**: Input Region Underflow via Insecure Offset Subtraction.

## 2. Technical Findings

### 2.1 OUROBOROS-FD-VM-02: OOB Sandbox Leak
- **Location**: `fd_vm_mem_haddr` in `fd_vm_private.h`.
- **Root Cause**: The macro `FD_VADDR_TO_REGION` calculates a region index from a virtual address but does not validate that the index is within the `region_haddr[6]` array bounds.
- **Exploit**: An attacker can provide a virtual address that maps to index 12, which overlaps with the `input_mem_regions` pointer in the `fd_vm_t` struct, leaking the base address of the sandbox metadata.
- **Formal Proof**: `2f09dc11ce85c4af`

### 2.2 OUROBOROS-FD-VM-01: Input Region Underflow
- **Location**: `fd_vm_find_input_mem_region`.
- **Root Cause**: Host address calculation uses `region->haddr + offset - region->vaddr_offset`. If an offset falls into a gap between fragmented regions, the binary search returns the next region, leading to `offset < region->vaddr_offset`. This causes an unsigned underflow, mapping the host address to memory BEFORE the allocated sandbox.
- **Exploit**: Arbitrary read/write of host memory outside the sandbox.
- **Formal Proof**: `80cbc8a829b564c9`
